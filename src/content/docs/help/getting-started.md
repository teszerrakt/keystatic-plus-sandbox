This site exists to test the editor. Every page is sample text, so change anything.

## Open the editor

Go to `/keystatic` and sign in with GitHub. Your first save starts a draft.

## What to try

- Edit this page and watch the draft bar.
- Add a picture from the Images page.
- Publish a draft, or throw one away.
